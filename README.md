# Healthcare Management System

A web-based Patient and Appointment Management System designed to help healthcare providers manage patient records, track appointments, record vital signs, and generate reports efficiently.

---

## 🚀 Features

* **Dashboard Overview:** Displays key metrics, stats, and quick links to core modules.
* **Patient Management:** Create, view, update, and manage patient health records.
* **Appointment Scheduling:** Book, track, and update appointment statuses.
* **Vitals Tracking:** Log and monitor essential patient vital signs over time.
* **Reports Module:** Generate summaries and analytical reports on patient records and appointments.
